# Interactive Manhwa Prototype

Экспериментальный прототип интерактивной манхвы с анимацией, привязанной к прокрутке.

## Цель первой версии

Проверить, приятно ли читать короткую вертикальную главу, где исходные иллюстрации слегка оживают при прокрутке: лёгкое приближение, движение камеры, дождь и почти статичные эмоциональные сцены.

На этом этапе без аккаунтов, подписок и автоматического разделения изображения на слои.
